# Order Jump Anomaly

**EN:** Adds a right-click order on navigation beacons placed near an anomaly: selected ships fly there and are sent through the anomaly automatically, so pilots no longer need the player to fly through it manually or to be hand-guided to its exact, tiny position.

**DE:** Fügt einen Rechtsklick-Befehl bei Navigationsbaken hinzu, die in der Nähe einer Anomalie platziert sind: ausgewählte Schiffe fliegen dorthin und werden automatisch durch die Anomalie geschickt, sodass Piloten nicht mehr darauf angewiesen sind, dass der Spieler selbst hindurchfliegt oder sie per Hand auf die winzige exakte Position lenkt.

*Requires: SirNukes Mod Support APIs (Workshop)*
